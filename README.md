# How to Download:

There are 2 methods to downloading All Respawn Maps

Method 1 (recommanded): Download the "RespawnMapsLauncher.exe" and run it.

Method 2: Download both the data.unity3d file and 8f315d69b7541bc9305dba5f50b332ca.bundle file. Then, copy & paste the data.unity3d file into the Stumble Guys_Data folder. After that, copy & paste the 8f315d69b7541bc9305dba5f50b332ca.bundle file into the StandaloneWindows64 folder (Stumble Guys_Data\StreamingAssets\aa\StandaloneWindows64).

I have provided method 2 as currently RespawnMapsLauncher.exe is flagged by VirusTotal as a virus :(
